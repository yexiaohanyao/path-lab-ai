# 三种论文形态：最终验收

验收日期：2026-09-12。

## 内容

- 三篇来自原论文卡片库的新选题，不重复此前六张样例中的论文；原始正文与 PNG 逐篇保留。
- 数学论文：274 条作者公开参与者记录，90 / 86 / 98 三组。复算 learningGain 均值为 1.8533 / 11.6233 / 17.0010 个百分点。明确原论文 p 值的适用范围，未将未显著差异表述为严格等效性证明。
- MatterGen：18 个真实候选晶体位点，CIF 与作者官方 data-release 对齐。SVG 1200×1600，72 个可编辑 text 节点，无 raster、无 foreignObject。四次实验均值 158±11 GPa、最高估值 169 GPa 与 200 GPa 目标分别标注；保留 2026 后续研究的质疑。
- 鸟类数字孪生：89 / 73 物种 AUC 从 Fig.5 源表提取；后验由 prior+delta 计算；Fig.1 录音时长将源数据秒数除以3600。空间地形、光点、轨迹与分层为叙事示意。

- 交互卡：题型筛选、3组开关、3个指标、空筛选、匿名记录、键盘访问、CSV/SVG/证据笔记下载、阅读判断与假设记录。

- 1440px桌面与390px手机检查；无全页水平溢出；本地HTTP与file模式检查；JavaScript错误为0。空间章节高亮与场景同步，手机章节标题未被固定场景遮住。
