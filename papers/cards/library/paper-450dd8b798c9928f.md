# 药剂学 × 深度学习

## 自驱动压片与处方优化

> 本地批次：LOCAL-08；源批次：PHARMACEUTICS-AI-20260909-01；网站状态：待本地确认。

### 论文来源

- 原论文：Accelerated drug development using a digital formulator and a self-driving tableting data factory
- 期刊/会议：Nature Communications（2026）
- DOI：[10.1038/s41467-026-71204-6](https://doi.org/10.1038/s41467-026-71204-6)
- 正式来源：[https://doi.org/10.1038/s41467-026-71204-6](https://doi.org/10.1038/s41467-026-71204-6)

### 01 数据与问题

- 研究问题：能否把材料性质、处方、压片过程和片剂质量测量整合进自动化片剂开发闭环，以模型指导处方与过程决策。
- 数据来源：自驱动压片数据工厂、历史CMAC片剂实验与Strathclyde Source Repository
- 数据集/样本：Digital formulator / tableting data factory dataset；Article Source Data
- 数据规模：材料到片剂模型共1199个压片数据点、170个处方、15种API、9种填充/黏合剂；训练653点/113处方，独立验证546点/57处方。
- 数据格式：tableting tabular data、raw-material descriptors、XLSX source data
- 数据类型：处方组成、原辅料物性、压片压力、孔隙率、抗张强度、粉体流动性
- 数据状态：论文提供Source Data；完整支撑数据与代码进入Strathclyde Source Repository，作者同时声明可按请求提供。

### 02 AI 怎么参与

- AI 技术：深度学习
- 核心方法：材料到片剂的混合预测系统含DNN集成，结合数字处方优化器和工厂内贝叶斯优化。

### 03 论文 Pipeline

1. 汇集材料与压片：汇集历史CMAC片剂与自驱动压片工厂的材料、处方、过程和逐片测量。
2. 训练混合预测：训练材料到片剂的DNN集成预测系统。
3. 数字优化处方：以预测质量属性筛选符合约束的处方与压片条件。
4. 自动压片检测：在自驱动工厂制片并采集逐片质量测量。
5. 独立验证指标：以独立处方与压片数据验证孔隙率和抗张强度预测。

### 04 指标与成果

- 重点指标：详见论文正文
- 代表结果：压片数据：1,199点、170个处方：（15种API、9种填充/黏合剂）
- 代表结果：独立验证：546点、57个处方：（独立于训练集）
- 代表结果：独立R²：孔隙率0.90；抗张强度0.89：（DNN集成预测）
- 代表结果：API使用：减少65%：（论文报告的开发流程）
- 使用边界：用于制剂研发与工艺探索，不能替代处方放行、GMP质量体系或监管所需的工艺验证。
