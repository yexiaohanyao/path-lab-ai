# 水泥材料 + 扩散模型

## 生成可验证的水泥浆微结构

### 论文来源

- 原论文：Generation of cement paste microstructure using machine learning models
- 期刊/会议：Developments in the Built Environment（2025）
- DOI：[10.1016/j.dibe.2025.100624](https://doi.org/10.1016/j.dibe.2025.100624)
- 源批次：CEMENT-AI-20260923-01

### 01 数据与问题

- 研究问题：基于真实水泥浆微结构切片，生成相组成、连通性与微力学性质接近真实样本的微结构。
- 数据来源：真实水泥浆SEM／BSE微结构切片
- 数据规模：约15000个128×128 BSE图像块
- 数据类型：背散射电子显微图像及微结构相分割
- 数据状态：数据可向作者申请，未见独立公开仓库

### 02 AI 怎么参与

- 核心方法：以U-Net为骨干的去噪扩散概率模型（DDPM）学习真实微结构分布。

### 03 论文 Pipeline

1. 采集拼接切片
2. 裁剪并标准化图像
3. 训练扩散模型
4. 生成微结构
5. 验证物相与力学

### 04 指标与成果

- 生成图像灰度统计接近真实图
- 三类主要物相分布与连通性合理
- 微力学分析支持相似性
- 使用边界：合成样本不能替代真实材料表征。
