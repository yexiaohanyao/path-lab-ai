# 中医学 × 视觉语言模型领域微调

## 舌象描述自动生成与体质推理

> 本地批次：LOCAL-06；源批次：B06-TCM-20260830；网站状态：待本地确认。

### 论文来源

- 原论文：Application of a Large Visual Language Model on Tongue Image Description Generation and Physical Constitution Reasoning in Traditional Chinese Medicine (TongueVLM): Model Development and Validation Study.
- 期刊/会议：JMIR Medical Informatics（2026）
- DOI：[10.2196/87237](https://doi.org/10.2196/87237)
- 正式来源：[https://doi.org/10.2196/87237](https://doi.org/10.2196/87237)

### 01 数据与问题

- 研究问题：舌象描述生成与体质推理
- 数据来源：中医舌象图文指令与三项独立测试集
- 数据集/样本：TongueVLM instruction data；three 3,000-case test tasks
- 数据规模：三项测试任务各3,000例，用于舌象识别、描述与体质推理
- 数据格式：舌象图像、中文问答与描述文本
- 数据类型：中医舌象、体质与证候文本
- 数据状态：论文说明数据可向作者合理申请，未提供独立公共数据集入口。

### 02 AI 怎么参与

- AI 技术：视觉语言模型领域微调
- 核心方法：在通用视觉语言模型上进行中医领域监督微调，联合输出舌象描述和体质推理。

### 03 论文 Pipeline

1. 整理舌象图像与中医图文指令
2. 构建舌象识别、描述和体质推理任务
3. 对视觉语言模型进行领域监督微调
4. 在三个各3,000例测试集评估
5. 比较LLaVA-OneVision并测量推理吞吐

### 04 指标与成果

- 重点指标：三任务Accuracy、相对提升、生成速度
- 代表结果：三项任务准确率分别为79.8%、78.6%和60.7%，较LLaVA-OneVision提升9.1、8.4和1.1个百分点；推理速度约24 token/s。
- 使用边界：数据需向作者申请；生成式输出仍需中医师审核，不能作为独立临床诊断。
