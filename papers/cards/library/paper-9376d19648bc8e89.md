# 药剂学 × 机器学习

## 拉曼光谱预测结肠释放

> 本地批次：LOCAL-08；源批次：PHARMACEUTICS-AI-20260909-01；网站状态：待本地确认。

### 论文来源

- 原论文：Machine learning of Raman spectra predicts drug release from polysaccharide coatings for targeted colonic delivery
- 期刊/会议：Journal of Controlled Release（2024）
- DOI：[10.1016/j.jconrel.2024.08.010](https://doi.org/10.1016/j.jconrel.2024.08.010)
- 正式来源：[https://doi.org/10.1016/j.jconrel.2024.08.010](https://doi.org/10.1016/j.jconrel.2024.08.010)

### 01 数据与问题

- 研究问题：能否从多糖包衣的拉曼光谱预测5-ASA释放曲线，并以未见包衣曲线检验泛化。
- 数据来源：60条公开释放曲线及其拉曼光谱＋新制备包衣验证实验
- 数据集/样本：Polysaccharide coating Raman-release dataset
- 数据规模：训练集为60条释放曲线及对应拉曼光谱；用2种新多糖包衣产生8条未见释放曲线作验证。
- 数据格式：Raman spectra、CSV/tabular release profiles、Python code
- 数据类型：拉曼光谱、多糖身份、孵育环境、2/8/24小时5-ASA释放率
- 数据状态：训练数据、8条新验证释放曲线、模型与代码均由论文官方GitHub公开。

### 02 AI 怎么参与

- AI 技术：机器学习
- 核心方法：光谱预处理/降采样，比较XGBoost、随机森林、LightGBM、SVM、KNN等模型并进行解释。

### 03 论文 Pipeline

1. 采集拉曼与释放：采集多糖包衣拉曼光谱和5-ASA释放曲线。
2. 预处理光谱：对光谱进行预处理和降采样。
3. 训练五类模型：比较XGBoost、随机森林、LightGBM、SVM、KNN等模型。
4. 验证未见曲线：用2种新多糖包衣形成的8条曲线作验证。
5. 解释关键特征：分析对释放预测有贡献的光谱特征。
