# 超声医学 + 视频深度表型学习

## 心脏超声定量：用视频深度表型学习完成三尖瓣反流识别与分级

> 本地批次：LOCAL-15；源批次：ULTRASOUND-AI-20260819-01；网站状态：待本地确认。

### 论文来源

- 原论文：Automated Deep Learning Phenotyping of Tricuspid Regurgitation in Echocardiography
- 期刊/会议：JAMA Cardiology（2025）
- DOI：[10.1001/jamacardio.2025.0498](https://doi.org/10.1001/jamacardio.2025.0498)
- 正式来源：[https://doi.org/10.1001/jamacardio.2025.0498](https://doi.org/10.1001/jamacardio.2025.0498)

### 01 数据与问题

- 研究问题：动态超声依赖操作者经验且图像噪声高、视角变化大，传统流程难以实现稳定的实时识别、分割与定量测量。
- 数据来源：MIMIC/PhysioNet
- 数据集/样本：详见论文正文
- 数据规模：开发数据含31,708名患者、47,312次检查和2,079,898段视频；外部测试含5,549次检查、278,377段视频及5,014名患者。
- 数据格式：超声视频与关键帧、DICOM/二维图像、多普勒时序、测量与病理标签
- 数据类型：彩色多普勒超声视频
- 数据状态：部分公开

### 02 AI 怎么参与

- AI 技术：视频深度表型学习
- 核心方法：将视频深度表型学习用于心脏超声定量，把彩色多普勒超声视频与三尖瓣反流识别与分级连接为可核验的超声医学AI流程。

### 03 论文 Pipeline

1. 采集动态超声：彩色多普勒超声视频
2. 定位解剖与时序信息：帧序列｜扫查视角｜测量标注
3. 训练视频深度表型学习：三尖瓣反流识别与分级
4. 实时与外部验证：多设备/多中心｜测量误差｜临床工作流

### 04 指标与成果

- 重点指标：论文报告外部验证
- 代表结果：视频深度表型学习完成三尖瓣反流识别与分级；论文报告：In both the internal and external test sets, AUC, F1 score, recall (sensitivity), positive predictive value (PPV), and negative predictive value (NPV) were calculated for clinically significant TR, which was defined as greater than moderate TR and severe TR.
- 使用边界：结论仅适用于论文报告的数据、任务与实验条件。
