# 水泥工业 + YOLOv8

## 实时识别水泥窑火焰、熟料与烟羽

### 论文来源

- 原论文：Deep Learning Techniques for Enhanced Flame Monitoring in Cement Rotary Kilns Using Petcoke and Refuse-Derived Fuel (RDF)
- 期刊/会议：Sustainability（2024）
- DOI：[10.3390/su16166862](https://doi.org/10.3390/su16166862)
- 源批次：CEMENT-AI-20260923-01

### 01 数据与问题

- 研究问题：根据水泥窑内部视频，随燃料和工况变化实时识别火焰、熟料与烟羽。
- 数据来源：水泥回转窑内部视频帧及三类区域标注
- 数据规模：数据集1为1225张（857训练、245验证、123测试），增强后2920张；数据集2为106张（75训练、20验证、11测试）
- 数据类型：工业视频帧、火焰／熟料／烟羽区域标注
- 数据状态：原始工业数据受保密协议限制，需向作者申请

### 02 AI 怎么参与

- 核心方法：YOLOv8实例检测与分割，结合迁移学习适应新工况。

### 03 论文 Pipeline

1. 采集窑内视频
2. 标注火焰、熟料与烟羽三类区域
3. 训练YOLOv8分割模型
4. 对新工况做小样本微调
5. 实时推理和评估

### 04 指标与成果

- 推理速度：25 FPS
- mAP@0.5：98.8%
- E9 mAP@0.5:0.95：72.8%
- 使用边界：仅作水泥窑操作辅助，不替代安全联锁与人工判断。
