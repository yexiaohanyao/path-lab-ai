# 神经医学 + AI脑电事件追踪

### 论文来源

### 01 数据与问题

- 研究问题：脑电与神经临床信息跨患者差异大、事件稀少且标注成本高，传统判读难以稳定完成连续监测、定位和预后评估。
- 数据来源：TUH EEG、CHB-MIT、PhysioNet及论文临床神经队列
- 数据集/样本：详见论文正文
- 数据规模：量化部分使用Bonn EEG数据：500段23.6秒记录，每段4,097个采样点，切分为11,500个1秒实例；质性部分包括7名医疗专业人员的焦点小组。
- 数据格式：EEG时序、脑网络连接特征、临床量表与病历、神经结局标签
- 数据类型：头皮EEG与临床事件
- 数据状态：未公开

### 02 AI 怎么参与

- AI 技术：AI脑电事件追踪
- 核心方法：将AI脑电事件追踪用于癫痫临床管理，把头皮EEG与临床事件与癫痫发作自动记录与照护路径连接为可核验的神经医学AI流程。

### 03 论文 Pipeline

1. 采集神经临床数据：头皮EEG与临床事件
2. 构建时空表征：EEG通道｜连接特征｜病历与量表
3. 训练AI脑电事件追踪：癫痫发作自动记录与照护路径
4. 神经结局验证：患者级测试｜跨中心｜临床适用边界

### 04 指标与成果

- 重点指标：论文报告模型校准
- 代表结果：AI脑电事件追踪完成癫痫发作自动记录与照护路径；论文报告：Additionally, the convolutional neural networks model outperformed other deep learning algorithms with an accuracy of 97.65%.
- 使用边界：结论仅适用于论文报告的数据、任务与实验条件。
